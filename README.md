About the Project

UniteMeal is a web-based food donation and rescue platform designed to reduce food wastage by connecting restaurants, food donors, NGOs, and volunteers. It helps surplus food reach people in need by making food donations, collection, and delivery coordination easier.

The platform provides different features according to the user's role, helping donors manage donations, NGOs discover and accept available food, and volunteers support food collection and delivery.

Key Features

- User Authentication: Sign in and access features according to your account role.
- Food Donations: Restaurants and donors can manage surplus food donations.
- Available Donations: NGOs can view available food donations and review pickup details.
- Donation Acceptance: NGOs can accept suitable donations for collection.
- Volunteer Management: NGOs can manage volunteers and assign them to pickups.
- Pickup Tracking: Users can coordinate and track donation collection and delivery.
- Donation History: View previous donation and collection activities.
- Dashboard: Access role-specific information and platform features.
- Reports and Analytics: Review donation-related information and activity.
- Database Integration: Store and retrieve application data through the backend and database.

Technology Stack

- Frontend: React, TypeScript, Vite
- Styling: Tailwind CSS
- Backend: Node.js, Express.js
- Authentication: Firebase Authentication
- Database: Supabase / PostgreSQL
- Deployment: Vercel and Render

Responsive Design and Device Compatibility

UniteMeal is designed to work across different devices, including desktop computers, laptops, tablets, and mobile phones.

Recommended experience: A PC or laptop is recommended for the best overall experience because the wider screen makes dashboards, donation listings, maps, tables, and management features easier to view and use.

The website also works on mobile devices. However, some navigation and layout elements may not be equally convenient on smaller screens.

Mobile Navigation Note

On mobile devices, a three-line (hamburger) menu may be visible. Currently, that menu does not provide additional navigation options. Instead, users can open the Profile page to access the other available features and navigation options.

This is a current navigation limitation and does not mean the entire website is unavailable on mobile. The platform remains accessible across devices, although a PC or laptop is recommended for easier navigation and a better overall user experience.

How to Use

1. Open the live website: https://unitemeal.vercel.app/
2. Sign in or register using the available authentication options.
3. Access the features available for your account role.
4. Donors can manage food donations.
5. NGOs can browse and accept available donations.
6. NGOs can manage volunteers and assign them to pickups.
7. Use the available dashboard, history, tracking, and reporting features as applicable to your account.

NOTE: Volunteer creation and some other function may not work for new user unless admin verify them, When verification is visible on user profile ,then all features are to be working.


Project Objective

The main objective of UniteMeal is to reduce food wastage and improve food distribution by connecting surplus-food donors with organizations that can distribute food to people in need.

The platform aims to make food rescue more organized, accessible, and efficient through a centralized digital system.
